## Stack del sitio

HTML y CSS escritos a mano, sin framework ni build. Un solo archivo autocontenido:
la foto va embebida como data URI, así que no hay assets externos que se rompan.

- Tipografía: Archivo · Source Serif 4 · JetBrains Mono (Google Fonts)
- Tema claro y oscuro con tokens CSS, respetando `prefers-color-scheme`
- Responsive sin media queries de más: una sola columna que gana un rail lateral en pantallas anchas
- Accesibilidad: HTML semántico, foco visible, `prefers-reduced-motion`
